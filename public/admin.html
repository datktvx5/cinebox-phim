Đang tải

Thiết lập tài khoản Google Cloud

  1. Bật Google Drive API trong Google Cloud Console.
  2. Tạo OAuth 2.0 Client ID loại Web application.
  3. Thêm Authorized redirect URI: https://ten-worker.workers.dev/api/admin/google/callback
  4. Cài đặt 3 secrets trên Cloudflare: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_TOKEN_KEY.
  5. Quay lại trang này rồi nhấn Liên kết tài khoản Google.

Lưu ý: dự án OAuth ở chế độ Testing có thể yêu cầu thêm tài khoản vào Test users và refresh token có thể hết hạn sau 7 ngày. Chuyển sang Production phù hợp với chính sách của Google.
